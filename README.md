# Smooth Chat / 流畅聊天

一个面向长对话的 SillyTavern 第三方前端扩展。

它每 15 轮对话自动生成增量摘要，并在后续模型请求中用“长期摘要 + 最近原文 + 尚未总结的消息”替代已经安全总结的旧楼层。同时使用 SillyTavern 原生消息加载上限，减少长聊天页面一次渲染的节点数量。

## 特点

- 默认每 15 轮总结一次；1 轮 = 用户消息 + 角色回复。
- 原始聊天记录永不删除。
- 默认保留最近 6 轮原文，维持短期语气与细节。
- 摘要失败、过期或正在重建时，不裁剪模型上下文。
- 编辑、删除或滑动已总结楼层后，自动检测并重建受影响摘要。
- 每个聊天独立保存摘要状态。
- 支持普通聊天和群聊。
- 可查看、手动编辑、立即生成、暂停或完全重建摘要。
- 默认首次只加载最近 60 条消息，旧楼层仍可通过酒馆原生“显示更多消息”查看。

## 不会修改什么

本扩展不会：

- 修改聊天气泡；
- 修改字体、字号或颜色；
- 修改背景、透明度、模糊、阴影或聊天宽度；
- 向聊天区域添加悬浮按钮、徽章或状态栏；
- 改写或删除聊天文件中的原始消息；
- 修改 `fast_ui_mode` 或用户自定义 CSS。

扩展自身的少量样式只作用于“扩展”抽屉内的设置区域。

## 安装

### 从本地文件夹安装

1. 将扩展文件夹命名为 `SmoothChat`。
2. 复制到以下任一位置：
   - 当前用户：`SillyTavern/data/<用户目录>/extensions/SmoothChat`
   - 所有用户：`SillyTavern/public/scripts/extensions/third-party/SmoothChat`
3. 重启 SillyTavern，或刷新浏览器页面。
4. 打开顶部的“扩展”抽屉，找到“流畅聊天”。

### 从 Git 仓库安装

将本项目发布到 Git 仓库后，在 SillyTavern 中打开：

`扩展 → 安装扩展 → 粘贴仓库 URL`

## 默认工作方式

1. 插件等待 15 个完整轮次。
2. 使用当前已连接的模型，把上一版摘要和新增 15 轮合并成新摘要。
3. 成功后，把摘要状态写入当前聊天的 metadata。
4. 下次正常回复前，仅在本次请求的临时消息数组中：
   - 注入长期摘要；
   - 保留最近 6 轮原文；
   - 保留尚未总结的全部消息；
   - 移除更早且已有有效摘要覆盖的消息。
5. 酒馆聊天数组与聊天文件保持不变。

如果模型调用失败或摘要与当前聊天不一致，第 4 步不会执行，酒馆会照常使用完整上下文。

## 设置说明

- **启用插件**：控制摘要注入和请求裁剪。
- **自动总结**：达到轮次阈值后自动调用当前模型。
- **限制首次加载的历史消息数量**：使用酒馆原生 `chat_truncation`，不改变主题样式。
- **每几轮总结**：默认 15。
- **最近原文保留轮数**：默认 6；越高越连贯，但上下文越长。
- **首次加载消息数**：默认 60；仅影响页面初次加载的消息节点。
- **摘要目标字数**：默认约 800 字。

“恢复原消息加载数”会还原插件首次启用前记录到的酒馆设置。

## 与酒馆内置 Summarize 的关系

建议不要同时启用两个自动摘要功能。否则可能：

- 重复调用模型；
- 同时向上下文注入两份摘要；
- 增加 token 消耗；
- 让模型收到不一致的长期记忆。

插件检测到内置摘要内容时，会在自己的扩展设置中显示提示，但不会擅自修改其他扩展。

## 风险与隐私

- 摘要由当前模型生成，可能遗漏细节或出现错误。重要剧情建议定期查看摘要。
- 自动摘要会产生额外模型调用和 token 消耗。
- 摘要存放在对应聊天 metadata 中，会随聊天文件一起保存在 SillyTavern 服务端。
- 本扩展不连接自己的服务器，不上传独立遥测数据。

## 开发验证

要求 Node.js 20 或更高版本。

```powershell
node scripts/check.mjs
node --test
```

自动化测试覆盖轮次识别、15 轮触发、增量 checkpoint、摘要失败降级、历史变更检测、请求期裁剪，以及不修改用户主题设置。

## 兼容性

- 目标：SillyTavern 1.14.0 或更高版本。
- 使用 `SillyTavern.getContext()`、chat metadata、`generateRaw()` 和 Prompt Interceptor。
- 不需要 Extras、服务器插件或外部数据库。
